The useful parts stay close.

Qubit is shaped around the moments that usually send a download workflow across too many windows: choosing a server, inspecting a torrent, adding the next thing, and checking what it belongs to.

01 / SWITCHBOARD

Multiple servers, one working view.

Keep per-server credentials, default save paths, categories, and local path mappings together. Move between a home machine, seedbox, or media box without losing the shape of the work.

02 / INSPECT

A torrent is more than a row.

Manage start, stop, force start, recheck, reannounce, and removal from the live list. Open a detail panel for general information, trackers, peers, and a navigable content tree with per-file priorities and download toggles.

03 / ADD + MATCH

From magnet to the right library.

Add a torrent from a file or magnet, catch duplicates by infohash, and optionally merge trackers. When content lands in a tagged Stash or Plex folder, Qubit can match it against the library and make the result available in the preview flow.

Built around the desktop

A remote with enough context to be useful.

Qubit keeps the qBittorrent Web API at the centre, then adds the small pieces that make a media-aware setup easier to operate from one place.

↳ 01

Live torrent control

Delta-polled torrent data, sortable and resizable columns, folder grouping, and per-row actions.

↳ 02

Media-aware previews

Sidecar screenshots, direct image previews, and an in-app player for matched Stash or Plex items.

↳ 03

Windows-native handoff

Package Qubit for Windows with .torrent and magnet associations through the Default-Apps picker flow.
