# Website cleanup and project portfolio plan

## Target structure

### `vincent.vandenbraken.com`

Make this the personal portfolio and professional home page.

- Personal introduction with Vincent's portrait.
- Detailed CV at `/cv`, also using the portrait in a restrained professional treatment.
- Four substantial project pages:
  - Groot
  - Uermend
  - Qubit
  - Vindicator
- Give every project the same level of polish, storytelling, media, and detail as the current Vindicator site.
- Use a shared portfolio framework, while allowing each project to keep its own visual identity.
- Derive the project stories, screenshots, links, and current status from the actual project repositories.
- The existing Vindicator-style spaceship animation may be reused here as an optional personal/project accent. It is not essential to the plan.

### `vincability.com`

Keep this as the consultancy/business site.

- Keep the existing consultancy content and identity.
- Add Vincent's portrait in an appropriate personal, about, or contact context.
- Remove Vindicator from the navigation and homepage identity.
- Do not redirect or replace the Vincability homepage.

### `www.vandenbraken.com`

Keep this as a small family/personal page for now.

- Remove Leydi and her links/content.
- Keep the remaining content for Vincent, Josefina, Benjamin, Puck, and Pearl.
- Avoid a major redesign or new investment.

## Portrait direction

Use the supplied photos as an identity reference set. Variants and treatments are allowed as long as they remain recognizably Vincent.

- Personal site: more expressive treatment.
- CV: neutral, professional crop.
- Vincability: warm, approachable treatment.
- Project pages: themed variants only when they still clearly look like Vincent.

Preserve distinctive features such as face shape, hairstyle/beard, eyes, and piercings. Prefer one optimized source set with responsive crops and sizes rather than repeatedly embedding large originals.

## Implementation order

1. Inventory the four project repositories and select the strongest real content and visuals.
2. Build the personal-site shell and move/confirm the detailed CV at `/cv`.
3. Add the portrait treatments and the four project entry points.
4. Build the Groot, Uermend, Qubit, and Vindicator pages to the Vindicator site's quality bar.
5. Remove Vindicator references from `vincability.com` while preserving its consultancy pages.
6. Remove only Leydi's content from `www.vandenbraken.com`.
7. Add cross-site links, preserve useful legacy URLs, and verify mobile layout, accessibility, metadata, and image performance.

Do not delete existing project or website content until the replacement routes have been checked and confirmed.
